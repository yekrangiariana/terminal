## Exporting

### HTML (Ctrl+E)

Exports a standalone HTML file with the full rendering engine baked in. Open it in any browser — the animation plays exactly as you see it. No server or dependencies needed. This is the best format for sharing interactive pieces.

### GIF

Captures a few seconds as an animated GIF. Good for social media and platforms that don't support interactive HTML. Larger file sizes than MP4, but universally supported.

### MP4

Records as H.264 video. Much smaller files than GIF with better quality. Best for high-res captures and video sharing.

*Requires a browser with WebCodecs support (Chrome, Edge). Hidden if unsupported.*

### Which Format?

- **Sharing on a website or portfolio** → HTML (interactive, tiny file)
- **Posting on social media** → GIF or MP4
- **High quality archive** → MP4
- **Quick preview to send someone** → GIF
