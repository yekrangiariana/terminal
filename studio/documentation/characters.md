## Characters &amp; Colors

The pattern produces a number for each cell. That number picks a **character** and a **colour**. Changing either of these completely transforms how the same pattern feels.

### Character Set

Characters are ordered from "quiet" (left) to "intense" (right). Low values in the pattern get characters from the left; high values from the right.

- **Short sets** (e.g. ` .:#`) → bold, high-contrast, poster-like
- **Long sets** (e.g. ` .:;+=xX#@`) → smooth gradients with more detail
- **Symbolic sets** (e.g. `░▒▓█`) → block graphics, retro terminal look
- **Single character** → everything becomes a density map in just colour

### Colour Palette

Colours map to the same index as characters — first colour goes with the first character, last with the last. The palette defines the mood.

### Palette Recipes

- **2 colours** (e.g. black + cyan) → bold, graphic, high-contrast
- **3–4 similar hues** (blues + purples, or greens + yellows) → cohesive, dreamy
- **3–4 opposing hues** (cyan + magenta, or orange + blue) → electric, vibrant
- **Many colours (6+)** → smooth gradients, subtle transitions
- **Monochrome** (single colour or white) → classic terminal aesthetic — all drama comes from character density

### Tips

- Click a colour chip to change it, right-click to remove it, **+** to add more
- The **Randomize Palette** dice gives surprisingly good results — try it several times
- Dark backgrounds with bright accent colours work best for dramatic visuals
- Try a single bright colour (e.g. green on black) for a Matrix / terminal look
