## About This Help

I wrote these docs while building this tool and learning how it all works. I'm not a mathematician or a graphics programmer — I'm figuring it out as I go, same as you probably are.

That means some of the explanations might be oversimplified, slightly off, or just plain wrong. If you spot something that doesn't seem right, or you know a better way to explain it, I'd genuinely love to hear about it.

### Get in Touch
