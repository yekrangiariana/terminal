## Keyboard Shortcuts

- <kbd>Ctrl+Z</kbd> — Undo (use freely — everything is reversible)
- <kbd>Ctrl+Shift+Z</kbd> — Redo
- <kbd>Ctrl+N</kbd> — New (reset to defaults)
- <kbd>Ctrl+E</kbd> — Export as HTML
- <kbd>Ctrl+R</kbd> — Randomise everything
- <kbd>Ctrl+M</kbd> — Toggle Math Reference
- <kbd>Space</kbd> — Play / Pause
- <kbd>F1</kbd> — Open Help
- <kbd>↑</kbd> / <kbd>↓</kbd> — Nudge a value input (hold Shift for 10× steps)
