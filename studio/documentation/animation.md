## Animation &amp; Time

Two controls govern how the animation moves. They do different things, and understanding the difference unlocks a lot of creative control.

### Frame Multiplier (fm)

This changes **what the motion looks like** — the shape and style of the movement.

- **0** — completely frozen; no motion at all
- **0.5–2** — gentle, flowing drift (great for calm, ambient loops)
- **5–20** — fast, energetic, chaotic movement
- **Negative values** — reverse direction (spirals unwind, rings contract)

**Try this:** Set a Spiral with fm = 1 for a slow hypnotic spin. Then try fm = -1 — it reverses.

### Animation Speed

This changes **how fast the clock ticks** — the playback tempo.

Think of it as a fast-forward / slow-motion dial. It doesn't change what the animation looks like, just how quickly it plays.

### The Difference (in one sentence)

**fm** changes the choreography. **Speed** changes the tempo.

A spiral with fm = 10 and slow speed looks different from fm = 1 and fast speed — even though both move at a similar pace. The first one has tight, rapid winding baked into its shape; the second is a smooth swirl played fast.

### Recipes

- **Ambient background:** fm 0.5–1, speed 0.2–0.4 → slow, dreamy drift
- **Energetic display:** fm 5–10, speed 0.3 → intense movement at moderate pace
- **Frozen art:** fm 0, speed 0 → static image (good for export as screenshot)
- **Slow-reveal:** fm 2, speed 0.1 → you can watch details unfold slowly
