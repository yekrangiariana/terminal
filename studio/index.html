Math Reference

All 11 pattern equations

Click any equation to paste it into your custom formula

Center Spiral — rotating arms winding outward
sin(atan2(dy,dx) + time*fm + sin(theta*yC) + gV*sin(x*xC+time))
xC = winding tightness, yC = arm curvature, gV = breathing depth

Circular — concentric rings from center
sin(dx*dx*xC + dy*dy*yC + time*fm)
xC/yC control ring density per axis — different values create ellipses

Mosaic — grid of cells from two crossing waves
sin(x*xC+time) * sin(y*yC+time)
xC = column count, yC = row count

Cross — crosshair interference pattern
sin(dx*dx*xC+time*fm) + cos(dy*dy*yC+time*fm)
xC = horizontal frequency, yC = vertical frequency

Checkerboard — tiled grid with shimmering columns
sin(x*xC) * sin(y*yC+time)
xC = column spacing, yC = row spacing

Diamond — diamond-shaped contour lines
sin((abs(dx)+abs(dy))*xC+time*fm) * cos(yC*atan2(dy,dx)+time)
xC = diamond density, yC = angular twist

Tunnel — infinite-zoom illusion
sin(xC/r+time*fm) * sin(theta*yC+gV*sin(r))
xC = zoom ring spacing, yC = twist, gV = ripple distortion

Plasma — classic demoscene undulating blobs
(sin(x*xC*0.01+time)+sin(y*yC*0.01+time*1.5)+sin((x+y)*xC*0.005+time*0.7)+sin(r*yC*0.01+time*1.2+gV))*0.25
Four sine waves summed for organic, flowing color

Interference — two wave sources cancelling & reinforcing
(sin(r*xC+time*fm+gV)+sin(r*yC+time*fm))*0.5
Bright bands where waves align, dark where they cancel

Radial Star — rose-curve flowers and petals
sin(r*xC + cos(theta*yC)*gV + time*fm)
yC = petal count, gV = petal sharpness, xC = ring density

Lissajous — parametric frequency dance
sin(x*xC*0.1+sin(time*3)*gV) * sin(y*yC*0.1+cos(time*2)*gV)
Two oscillators at different frequency ratios

Extra formulas to try

sin(r*0.2 + theta*3 + time) — Spinning flower
sin(x*0.1+time)*cos(y*0.05+time*1.5)+sin(r*0.05) — Rippled waves
cos(theta*5)*sin(r*0.1+time)+sin(theta*3+time*2)*cos(r*0.05) — Dual rose
sin(x*y*0.001+time)+cos(r*0.1-time*0.5) — Hyperbolic ripple
fract(r*0.1 + time*0.5) * sin(theta*6) — Sawtooth rose
smoothstep(0.3, 0.7, sin(r*xC+time)) * noise(dx, dy+time) — Noisy threshold rings

Shader-style functions — click to try

fract(r*0.1 + time) — fractional part (repeating sawtooth)
mod(x+time*20, 40) * mod(y, 30) * 0.001 — remainder (tiling/wrapping)
clamp(sin(r*xC+time), -0.5, 0.5) — constrain range (capped waves)
mix(sin(r*0.1+time), cos(theta*5+time), 0.5) — interpolation (blend two patterns)
step(0.5, sin(r*xC+time)) * sin(theta*yC) — hard cutoff (binary rings)
smoothstep(0.2, 0.8, sin(r*0.1+time)) * sin(theta*6) — soft threshold (smooth rings)
noise(dx*0.05+time, dy*0.05) + sin(r*0.1) — 2D value noise (organic texture)

Quick reference

Variables: x y dx dy r theta time w h xC yC fm gV
Trig: sin cos tan asin acos atan atan2
Math: abs sqrt pow exp log floor ceil round sign min max
Shader: fract mod clamp mix step smoothstep noise
Constants: PI TAU E   Operators: + - * / % ()

Transform pipeline

screen → center offset → rotate → scale → symmetry fold → turbulence warp → pattern
Every pixel goes through this chain before reaching the pattern equation.
